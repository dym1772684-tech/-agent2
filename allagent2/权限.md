当用户输入问题后，成熟的智能体系统在进行意图识别和任务拆解之前，第一步必须在 API 网关与引导预处理层（API Gateway / Bootstrap Layer） 完成一套严格的“零信任安全拦截与权限装配”流水线。

这一过程通常在代码中通过预处理函数（如 bootstrap._prepare 或网关中间件）瞬间完成，具体包含三个核心子步骤：

1. 身份识别与认证 (Authentication & Identity)
核心动作：解析请求携带的凭证（如 JWT、Session Cookie 或 API Key）。

处理逻辑：

验证凭证的合法性、签名及有效期。

提取并锁死当前用户的唯一标识（user_id）与系统角色（如 admin、nurse、common）。

检查账户实时状态（如是否存在登录锁定或已被降权）。

2. 请求校验与安全清洗 (Request Validation & Sanitization)
核心动作：在进入任何业务和 AI 推理逻辑前，对输入进行格式、频率与合规性校验。

处理逻辑：

结构化校验：使用严格的 Schema（如 Pydantic）校验输入载荷的类型、长度和字段结构。

频控与防刷：基于 Redis 滑动窗口进行速率限制（Rate Limiting），防止恶意高频请求或 DDoS。

安全红线拦截：进行敏感词、SQL 注入特征、Prompt 注入（Prompt Injection）倾向以及高危隐私数据（PII）的扫描。一旦命中违规，直接在网关层中断并返回 403 或 451，零 Token 消耗。

3. 权限范围装配 (Permission Scope Assembly)
核心动作：构建不可篡改的运行时权限上下文（PermissionContext）。

处理逻辑：

功能级权限装配：查询并加载该角色拥有的动作白名单（如是否具备读取档案、修改健康数据或调用系统指标的权限）。

对象级 ACL 绑定：确定该用户的数据边界（例如：家属/普通用户只能操作与其绑定的特定老人 elder_id 列表，管理员具备全局豁免权）。

状态挂载：将上述权限规则固化为一个结构体，直接注入后续智能体状态（State）的底层，供后续所有工具调用和数据查询进行硬性鉴权。 根据这个重新再把计划列举
